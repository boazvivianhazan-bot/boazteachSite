# ניהול שיעורים פרטיים

אפליקציית ווב אישית לניהול שיעורים פרטיים: יומן עם שעות פנויות, קביעת שיעורים, שיעורים קבועים, תלמידים, התראות התנגשות וסיכום חודשי עם ייצוא לאקסל. ניתן להתקין אותה בטלפון כאפליקציה.

האתר סטטי לגמרי (GitHub Pages). כל הנתונים נשמרים **בחשבון הגוגל שלך בלבד** — ביומן Google ובגיליון בשם `Lessons DB` בדרייב.
אין שרת, ושום מידע אישי (תלמידים, כתובות, קודי בניין) לא נשמר בקוד, במאגר או ב-localStorage.

## מה יש באפליקציה

| מסך | מה עושים בו |
|---|---|
| **יומן** | תצוגת יום (טלפון) / שבוע (מחשב) עם כל האירועים מהיומנים המוצגים, הצעות לשעות פנויות (ירוק) ושעות "צמודות" ללא הפסקה (מקווקו). לחיצה על כל שעה או אירוע → קביעת שיעור. כפתור "העתק שעות פנויות" לוואטסאפ. |
| **קביעת שיעור** | בחירת תלמיד מהרשימה (או תלמיד חדש), סוג שיעור, ×1/×2/×3, מחיר, שיעור קבוע כל שבוע, שיעור שכבר התקיים. אזהרות על חפיפה, הפסקה קצרה, שעות עבודה ו"משמרת מוקד" — אף פעם לא חוסמות. |
| **תלמידים** | חיפוש, כרטיס תלמיד עם התקשרות / וואטסאפ (להורה אם הוגדר) / Waze, יתרה לתשלום, היסטוריה ושיעורים קבועים. |
| **סיכום חודשי** | בחירת חודש, כרטיסי סיכום, פילוח לפי סוג ולפי תלמיד, גרף הכנסה, טבלת שיעורים עם סימון התקיים / שולם / בוטל, וייצוא לאקסל. |
| **הגדרות** | סוגי שיעור ומחירים, שעות עבודה לכל יום, יומנים מוצגים, הדגשת אירועים (למשל "מוקד"), מחיקת נתוני בדיקה. |

התראת **"⚠️ X שיעורים מתנגשים"** בראש המסך בודקת את 4 השבועות הקרובים מול האירועים ביומן, כללי ההדגשה וחגי ישראל (ערב חג — מ-13:00).

## דרישות

- Node.js 20 ומעלה
- חשבון Google
- חשבון GitHub

## הקמה — שלב אחר שלב

### 1. יצירת Client ID ב-Google Cloud

1. היכנס ל-[Google Cloud Console](https://console.cloud.google.com/) וצור פרויקט חדש (למשל `tutoring`).
2. **APIs & Services → Library** — הפעל את שלושת ה-API:
   - Google Calendar API
   - Google Sheets API
   - Google Drive API
3. **APIs & Services → OAuth consent screen** (או **Google Auth Platform**):
   - User type: **External**
   - מלא שם אפליקציה ואימייל.
   - בלשונית **Audience** הוסף את כתובת הג׳ימייל שלך תחת **Test users**.
     (כל עוד האפליקציה במצב Testing רק משתמשי בדיקה יכולים להתחבר — זה בדיוק מה שצריך כשאתה המשתמש היחיד.)
4. **Credentials → Create credentials → OAuth client ID**:
   - Application type: **Web application**
   - **Authorized JavaScript origins** — הוסף:
     - `http://localhost:5173` (לפיתוח מקומי)
     - `https://<שם-המשתמש-שלך>.github.io` (בלי נתיב ובלי `/` בסוף)
   - אין צורך ב-Redirect URIs.
5. העתק את ה-**Client ID** (נגמר ב-`.apps.googleusercontent.com`).

### 2. הדבקת ה-Client ID

פתח את `src/config.ts` והחלף את הערך:

```ts
export const GOOGLE_CLIENT_ID = '1234567890-abc.apps.googleusercontent.com'
```

ה-Client ID אינו סוד ומותר שיהיה במאגר ציבורי.

### 3. הרצה מקומית

```bash
npm install
npm run dev
```

פתח את http://localhost:5173 והתחבר.

### 4. העלאה ל-GitHub Pages

1. צור מאגר חדש ב-GitHub (למשל `boazteachSite`). ב-GitHub Pages בחשבון חינמי המאגר צריך להיות **ציבורי** — אין בו שום מידע אישי.
2. דחוף את הקוד לענף `main`:
   ```bash
   git init -b main
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
3. במאגר: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. כל דחיפה ל-`main` מריצה את ה-workflow שבונה ומפרסם את האתר אל
   `https://<user>.github.io/<repo>/`. ה-`base` של Vite נקבע אוטומטית לפי שם המאגר.
5. ודא ש-`https://<user>.github.io` מופיע ב-**Authorized JavaScript origins** (שלב 1.4).

### 5. התקנה בטלפון

- **Android (Chrome):** פתח את כתובת האתר → תפריט ⋮ → **התקנת אפליקציה** (או "הוספה למסך הבית").
- **iPhone (Safari):** פתח את כתובת האתר → כפתור השיתוף → **הוספה למסך הבית**.

האפליקציה נפתחת במסך מלא עם אייקון משלה. בלי אינטרנט נפתח רק מסך האפליקציה — הנתונים עצמם תמיד נטענים מגוגל.

## הגיליון `Lessons DB`

| לשונית | תוכן |
|---|---|
| `LessonTypes` | סוגי שיעור, משך, מחיר, זום, צבע |
| `Students` | תלמידים, פרטי קשר, הורה, סוגי שיעור |
| `Lessons` | כל שיעור — שורה אחת (כולל המחיר בפועל, כך שחודשים קודמים לא משתנים כשמחירים משתנים) |
| `Series` | שיעורים קבועים (כל שבוע). כל שבוע הוא שורה נפרדת ב-`Lessons` ואירוע נפרד ביומן |
| `Settings` | הגדרות (שעות עבודה, יומנים, כללי הדגשה ועוד) |

- שורות לא נמחקות: שיעור שבוטל נשאר בסטטוס `cancelled`, שיעור שנדחה — `postponed`. המחיקה היחידה היא **הגדרות → מחיקת נתוני בדיקה**.
- **מותר לערוך את הגיליון ידנית.** האפליקציה מוצאת כל שורה לפי המזהה שלה ואת העמודות לפי הכותרת, ממלאת שורות ריקות, ומתקנת בטעינה שורות בלי מזהה או עם מזהה כפול.
- אירועים ביומן משתנים או נמחקים **רק** אם האפליקציה יצרה אותם (מסומנים בסימון פרטי). אירועים שיצרת בעצמך לא נוגעים בהם.

## התחברות והרשאות

ההתחברות מתבצעת ישירות בדפדפן עם Google Identity Services. ההרשאות המבוקשות:

| הרשאה | למה |
|---|---|
| `calendar.events` | יצירה, עדכון וביטול אירועי שיעורים |
| `calendar.readonly` | קריאת אירועים מהיומנים המוצגים, רשימת יומנים ולוח החגים |
| `spreadsheets` | קריאה וכתיבה לגיליון `Lessons DB` |
| `drive.file` | יצירת הגיליון ומציאתו מחדש לפי שם |

אסימון הגישה תקף כשעה. כשהוא פג מופיע פס "התחבר מחדש" — הטופס שמילאת נשאר במקומו.
האסימון נשמר רק בזיכרון וב-sessionStorage של הלשונית (נמחק בסגירתה).

חגים נקראים מלוח החגים הציבורי של Google; רק אם הוא לא זמין נשלחת בקשה ל-Hebcal (טווח תאריכים בלבד, בלי מידע אישי).

## פיתוח

- `npm run dev` — שרת פיתוח. 
- `http://localhost:5173/?mock` — מצב הדגמה עם נתוני גוגל מדומים (לא נוגע בחשבון האמיתי, מתאפס בכל רענון). קיימים גם `?mock=demo` (תלמידים, שיעורים, סדרה, חגים) ו-`?mock=messy` (גיליון "מבולגן" לבדיקת התיקון האוטומטי). קוד ההדגמה לא נכלל בגרסה המפורסמת.
- `npm run build` — בדיקת טיפוסים ובנייה ל-`dist/`.
- `node scripts/make-icons.mjs` — יצירת אייקוני האפליקציה מחדש.

## מבנה הפרויקט

```
src/
  config.ts            ← Client ID, הרשאות, אזור זמן
  auth/                ← התחברות לגוגל וניהול האסימון
  data/                ← הגיליון (db.tsx), אירועים, שיעורים, סדרות, התנגשויות, סיכומים
  lib/                 ← קריאות ל-API של גוגל, אזור זמן, חישוב שעות פנויות, חגים, אקסל
  components/          ← רכיבי ממשק משותפים
  screens/             ← מסכי האפליקציה
  dev/                 ← מצב הדגמה (פיתוח בלבד)
public/                ← manifest, service worker, אייקונים
.github/workflows/     ← פריסה ל-GitHub Pages
```
